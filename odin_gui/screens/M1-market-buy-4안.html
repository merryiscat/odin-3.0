마켓 — 구매 목록 (M1) — 화면 4안

목적 내 매매 조합에 끼울 모델(부품)을 찾아 성적으로 비교하고 고른다. 부품 4종: 시장 상태 판단 · 종목 고르기 · 사고팔기 규칙 · 돈 배분/위험 관리.
진입점 사이드바 "마켓" → 기본 탭 "구매".
다음 모델 클릭 → 모델 상세(구매 결정, 화면 미정) · 탭 "판매" → M2 판매(업로드).
가정 로그인 상태. 목록의 모든 모델은 검증(규격·안전 자동 검사 + 과거 데이터 백테스트) 통과분만 노출. 가격 방식 미정(보류 #15) → {가격} 토큰.

의도

4안 공통: 목록에는 검증 통과 모델만 올라온다(검증 배지는 상태 표시지 추천이 아님). 기준선 모델을 비교 줄로 항상 함께 보여 "운으로 번 모델"을 걸러낼 눈을 준다. 성적 옆에 "과거 성적이며 미래 수익 아님"을 고정 — 유료 판매 화면이라 투자 권유로 읽히는 표현(추천·보장)은 쓰지 않는다(보류 #5 법적 검토 전 최소 안전선). 보편 A는 같은 종류끼리 숫자 비교, 보편 B는 둘러보기, 실험 A는 내 조합에 끼웠을 때의 효과, 실험 B는 시장 상황별 강약.

대안

판매자 순위(누가 잘 만드나)를 앞세우는 안 — 사람보다 모델 성적이 기준이라 보류. 인기순(구매 수) 정렬 — 성적과 무관한 쏠림을 부추겨 기본 정렬에서 제외. 실험 A·B를 보편 A의 보조 보기(토글)로 합치는 혼합안.

미정

종류별 성적 지표: 사고팔기=수익률·낙폭, 종목 고르기=초과 수익, 시장 상태 판단=기준선 대비 적중, 돈 배분=낙폭·변동성 — 확정 필요. 백테스트 기간·비용(수수료·세금·슬리피지) 가정. 가격 표기(과금 방식 보류 #15). 화면 용어 "모델"과 개념 문서 "모듈(부품)" 통일. 모델 상세 화면(구매 결정) 설계. 실행 위치(보류 #14)에 따라 "구매 후 어디서 도는지" 안내 필요 여부.
