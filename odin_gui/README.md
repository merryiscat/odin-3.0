# odin_gui — GUI 모듈 (사용자가 설치하는 앱)

> 데이터 흐름: 보다 → 판단 → 실행 → **[보여주다]**.

## 하는 일
사용자가 자기 컴퓨터에 까는 앱(= .exe). **화면.**
계산은 하지 않고 **표(DB)를 읽어서 보여주기만** 한다.

- **읽기**: 국면 표, 주문 의도 표, 체결 기록 표 등.
- 첫 목표(오픈코어 ②의 시작): **읽기전용 시장정보 대시보드** — 사람들이 보고 스스로 매매.

## 공개/비공개
- **화면 껍데기**: 공개 가능.
- **증권 키 저장 로직**은 안전하게(OS 비밀 저장소). 키는 이 앱(사용자 PC)에만 두고
  내 서버·공개 코드·로그 어디에도 보내지 않는다.

## 참고
- GUI 워크스페이스를 사용자가 따로 열어둠 → 이 폴더와 합칠지 경로 확인 필요(브레인 §9).
