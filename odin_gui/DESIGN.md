## 미학 방향 — "Koyfin 문법" (v7 스킨, 2026-09-14)

**다크 크롬 + 라이트 데이터 캔버스.** 틀(상단바·사이드바)은 어둡게 가라앉히고,
데이터가 놓이는 본문은 밝은 회색 캔버스 위 **흰 패널**로. 정보 밀도는 높게 —
패널마다 머리줄(제목+핵심 숫자), 본문은 촘촘한 표·작은 섹션 라벨.
- 이전 방향 폐기 이력: v5 인더스트리얼 다크(탈락) → v6 클린 라이트(탈락 "끔찍") → **v7 Koyfin**.
- 중세풍 오딘 컨셉 스킨은 여전히 추후(docs/pending.md #10).

## 구조 문법

- **상단바+사이드바 = 전 화면 공통 규격**(2026-09-16 사용자 확정, 기준 구현 = `app/market-temp.html`):
  새 화면은 이 두 크롬을 그대로 복사해 쓰고, 화면별 컨트롤(탭·날짜 등)만 상단바 우측에 얹는다.
- **상단바**(48px, 다크): 워드마크 + 상태 시각 + 우측에 화면별 컨트롤.
- **사이드바**(192px, 다크): **제목**(파이프라인·마켓·연구소·계좌·리서치 — 14px 굵게. 계좌만
  링크, 나머지 제목은 구분자라 클릭 = 접기 ▾/▸) + **소제목**(그 아래 항목 — 12px, 34px 들여쓰기).
  활성 = 밝은 글자 + 배경 한 톤 업 + 좌측 2px 액센트. 마켓 하위 = 리스트(모델 목록)·업로드.
  연구소 하위 = 피쳐셋 분석·모델·실험(2026-09-16).
- **본문**: 밝은 캔버스, 패널 그리드(gap 12px). 패널 = 흰 바탕 + **1px 테두리 + radius 4px** +
  머리줄(제목 13px 800 / 우측에 핵심 숫자) + 본문(padding 14px).
- 패널 안 소제목은 대문자풍 작은 라벨(10.5px, 자간 넓게, muted).
- 나열 데이터는 타일보다 **표**를 우선(Koyfin 문법) — 행 구분은 1px 라인.

## 타이포그래피

- **SUIT Variable** 단일 서체 — Koyfin처럼 **숫자도 본문체**로(tabular-nums 필수), 모노 서체는
  상단바 시각 표시 등 최소한만. 오프라인 폴백 'Malgun Gothic'.
- 크기 문법(밀도 우선): 소제목 10.5px / 본문·표 12~13px / 패널 제목 13px 800 /
  핵심 숫자 16px 700 / 상태 워드 30px 800. 가중치 대비는 400 vs 700~800.
