# Odin 3.0

한국 주식시장을 **보고(데이터) → 판단하고(시장 국면·매매 모델) → 실행하고(안전장치 건 주문) →
보여주는(설치형 앱)** 자동매매 시스템을 새로 짓는 프로젝트입니다.
모듈끼리는 코드로 서로 부르지 않고 **DB 표로만** 주고받습니다.

**현재 단계**: 초기 개발 — 원천 데이터 적재(`data_pipeline`)와 시장 국면 판정 1층
(`state_module`), 첫 화면 시안(`odin_gui`)을 만드는 중입니다. 아직 실제 매매는 하지 않습니다.

## 폴더 안내

| 폴더 | 하는 일 |
|------|---------|
| `data_pipeline/` | KIS·DART·KRX에서 원천 데이터를 긁어 적재 |
| `state_module/` | 지금 시장이 어떤 국면인지 판정 |
| `model_module/` | 국면을 읽어 "주문 의도"를 냄 |
| `execution_module/` | 안전장치를 걸고 실제 주문 |
| `odin_gui/` | 사용자가 설치하는 화면 앱 |
| `db/` | 표 설계(스키마 SQL) |

## 시작하기

각 모듈은 독립된 파이썬 프로젝트(uv)입니다. 예를 들어 데이터 적재는:

```
cd data_pipeline
uv sync
```

API 키는 `.env.example`을 복사해 `.env`로 만들고 채웁니다
(`scripts/setup-keys.cmd`가 대화식으로 안내). **실제 키가 든 `.env`는 절대 커밋하지 않습니다.**

## 면책

교육·연구 목적의 개발 중인 코드입니다. **투자 자문이 아니며 수익을 보장하지 않습니다.**
이 코드를 사용해 발생하는 손실은 전적으로 사용자 본인의 책임입니다.
