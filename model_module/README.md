# model_module — 매매모델 모듈 (표준 플러그인)

> 데이터 흐름: **보다 → [판단(뒷부분)] → 실행 → 보여주다.** 마트(장터)의 단위.

## 하는 일
상태값(국면)을 받아서 → **"주문 의도"**(뭘·얼마·사라/팔라)를 낸다.
낸 주문 의도는 **표(DB)에 쓴다.** 다음 모듈(`execution_module`)이 읽는다.

- **읽기**: `state_module`이 쓴 국면/상태 표.
- **쓰기**: 주문 의도 표(예: `order_intent`).

## 중요한 안전 규칙
- 모델은 **"임의 코드"가 아니라 "검증된 엔진 위의 설정/파라미터"** 로 만든다(보안·안전).
  = 남이 아무 코드나 실행하게 두지 않는다.
- 모델은 **제안만** 한다. 실제 주문·가드는 `execution_module`이 소유한다.

## 공개/비공개
- 플러그인 **틀·기본 모델**: 공개 가능.
- **잘 되는(프리미엄) 모델**: 비공개.
