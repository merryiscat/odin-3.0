# 시장 상태 판단 — 입출력 규격 v1

> 마켓에 올릴 **시장 상태 판단 모델**이 지켜야 하는 계약. 2026-09-16 기준, **실제로 돌고 있는 표·값**으로 작성.
> 여기 적힌 칸·단위·값은 그날 DB에서 직접 확인한 것이고, 예시 줄도 실제 적재분이다.
> 규칙 숫자(어떻게 판정하는지)는 `state_module/README.md`, 표 정본은 `db/*.sql`.

## 한 줄 계약
```
[읽는다]  원천 표(지수 일봉·1분 시세·바스켓 명부) + 공용 파라미터(state_params)
[낸다]   state_market_temp 에 한 줄 — 상태 코드 하나 + 근거(metrics)
```
- 모델은 **DB 표로만** 주고받는다. 외부 API·증권 키·주문에 접근하지 않는다.
- 같은 시각에 여러 모델이 각자 한 줄씩 낼 수 있다(`model_id`로 구분). 서로의 줄을 고치지 않는다.
- **append만** — 이미 쓴 줄은 고치거나 지우지 않는다.

## 1. 입력 (읽기 전용)

### 1-1. `raw_index_ohlc` — 지수 일봉
배경(이동평균)·1년 분포의 재료. 한 시장 하루 한 줄.

| 칸 | 뜻 | 실제 예시 (2026-09-15 코스피) |
|---|---|---|
| `date` | 거래일 | `2026-09-15` |
| `market` | 시장 코드 | `KR-KOSPI` / `KR-KOSDAQ` |
| `open` `high` `low` `close` | 시가·고가·저가·종가 (지수 포인트) | 6659.25 · 6715.46 · 6582.2 · 6627.26 |
| `volume` | 거래량 | 274038 |
| `trade_value` | 거래대금 — **백만원 단위** | 16245351 (= 약 16.2조) |
| `source` | 출처 | `old_odin`(옛 오딘 복사) / `kis` |

### 1-2. `raw_market_snapshot` — 1분 시세 (원료)
`kind`로 종류를 나눠 한 표에 쌓는다. **종목은 한 종목당 한 줄**(묶음 아님).

| 칸 | 뜻 | 지수 줄 예시 | 종목 줄 예시 |
|---|---|---|---|
| `ts` | 수집한 분(한국시간) | `2026-09-16T09:47:00+09:00` | 같음 |
| `market` | 시장 | `KR-KOSPI` | `KR-KOSDAQ` |
| `kind` | `index` / `stock` / `expected_index` / `us_futures` | `index` | `stock` |
| `code` | 지수코드 또는 종목코드 | `0001`(코스피) · `1001`(코스닥) | `003380` |
| `price` | 현재가 (지수=포인트, 종목=원) | 6675.77 | 11090.0 |
| `change_pct` | 전일 종가 대비 % | 0.73 | −1.33 |
| `acc_volume` | 당일 누적 거래량 | 49318 | 39852 |
| `acc_amount` | 당일 누적 거래대금 — **지수는 백만원, 종목은 원** | 3518667 | 445040465 |
| `source` | `kis`(3.0 직접 수집) / `old_odin`(밤 복사) | `kis` | `kis` |

주의:
- `old_odin` 줄에는 `acc_amount`가 **없다**(옛 오딘이 대금을 안 받아옴) → 대금 배율은 `kis` 줄에서만 나온다.
- 같은 분에 두 출처가 있으면 `kis`를 먼저 쓴다.
- 종목 코드는 6자리 영숫자(신형 우선주 `0001A0` 같은 값도 실제로 들어온다).

### 1-3. `dim_basket` — 바스켓 명부 (매일 아침 갱신)
| 칸 | 뜻 | 예시 |
|---|---|---|
| `basket_type` | `leader`(업종 대장주 — 폭·역행 측정) / `proxy`(시총 상위 — 장외 시간 지수 대용) | `leader` |
| `market` `stock_code` | 시장·종목코드 | `KR-KOSPI` · `000720` |
| `sector_l1` | 그 종목이 대장인 업종 (leader만) | `건설·엔지니어링` |
| `rank_no` | 시총 순위 (proxy만) | `null` |
| `as_of` | 명부를 뽑은 날짜 | `2026-09-16` |

### 1-4. `state_params` — 공용 파라미터 (모든 모델이 같은 입력을 읽는다)
계산은 오딘이 한 번만 하고, 모델은 읽기만 한다. `scope` 두 가지.

**`bg_daily`** — 아침 1회, 어제까지 일봉으로. 장중엔 안 변함. (실제 줄: 2026-09-15 코스닥)

| 키 | 뜻 | 실제 값 |
|---|---|---|
| `as_of_date` | 계산에 쓴 마지막 거래일 | `2026-09-15` |
| `prev_close` | 전일 종가 | 812.41 |
| `ma20` | 20일 이동평균 | 820.7565 |
| `ma_gap_pct` | 전일 종가와 이평의 거리 % | −1.0169 |
| `ma_slope_pct` | 이평의 5거래일 변화율 % | −1.0241 |
| `chg5_pct` | 최근 5거래일 누적 등락률 % | 0.0653 |
| `money_avg20` | 직전 20거래일 평균 대금(백만원) | 6008208.8 |
| `surge_threshold` | 대금 폭증 경계(= 배율이 이 값 이상이면 폭증). 최근 1년 분포 상위 10% | 1.3341 |
| `surge_hist_n` | 그 분포의 표본 수 | 243 |

**`intraday`** — 매분. (실제 줄: 2026-09-16 09:46 코스피)

| 키 | 뜻 | 실제 값 |
|---|---|---|
| `index_price` `index_chg` | 지수 현재가·당일 등락률 % | 6682.95 · 0.84 |
| `acc_amount` | 지금까지 누적 대금(백만원) | 3455555 |
| `money_ratio` | 대금 배율(지금 ÷ 과거 같은 시각 평균). 이력 부족이면 `null` | `null` |
| `money_hist_days` | 그 평균에 쓴 과거 일수 | 0 |
| `surge_threshold` | 위 배경값 복사(그 분 판정에 쓴 경계) | 1.4136 |
| `breadth_n` | 등락률을 받은 대장주 수(분모) | 21 |
| `breadth_up` `breadth_down` | 오른/내린 대장주 수 | 8 · 13 |
| `breadth_u05` `breadth_d05` | +0.5% 이상 / −0.5% 이하 대장주 수 | 5 · 8 |
| `sector_chg` | **업종별 대장주 등락률** (업종 이름 → %) | `{"화학": 2.95, "반도체·전자": 1.11, "건설·엔지니어링": -2.42, …}` |

- 공통 칸: `ts`(계산 시각) · `market` · `scope` · `calc_ver`(현재 `params-v1`).
- 계산식이 바뀌면 `calc_ver`가 올라간다 — 모델은 자기가 검증받은 `calc_ver`를 기록해 두는 게 좋다.

## 2. 출력 — `state_market_temp` 한 줄

| 칸 | 필수 | 뜻 · 허용값 |
|---|---|---|
| `ts` | ✔ | 판정을 **쓴 시각** (한국시간) |
| `as_of` | ✔ | 판정에 쓴 **데이터의 시각**. 지연되면 `ts`와 벌어진다(신선도 확인용) |
| `market` | ✔ | `KR-KOSPI` / `KR-KOSDAQ` (해외 확장 시 8시장 코드) |
| `model_id` | ✔ | 내 모델 이름 — `dim_model`에 먼저 등록돼 있어야 한다 |
| `scope` | ✔ | `rt`(실시간, 오늘의 단면) / `w`(주간, 최근 5거래일 성격) |
| `horizon` | ✔ | `now`(지금 상태). 미래를 맞히는 모델은 `d1`·`w1` 등 |
| `basis` | ✔ | `live`(장중 1분) / `eod`(종가 확정) / `pre`(아침 프록시) / `after`(저녁 프록시) |
| `state_code` | ✔ | **상태 하나** — 아래 어휘표의 코드. 여러 조건이 맞아도 우선순위 하나만 |
| `state_sectors` | | `theme_up`일 때 역행 상승 업종 목록(배열). 그 외 `null` |
| `state_conf` | | 확신도 0~1. 규칙 모델은 비워 둠(급락 + 대장주 전원 하락일 때만 1.0) |
| `breadth_up` `breadth_down` `breadth_total` | | 대장주 집계(오른 수·내린 수·분모). 폭을 안 쓰는 모델은 `null` |

| `metrics` | ✔ | 판정 근거 묶음(아래) |
| `rule_ver` | ✔ | 판정 규칙 버전. 숫자를 바꾸면 올린다 |

### `metrics`에 무엇을 넣나
"왜 그렇게 판정했나"가 나중에 재현되도록 **판정에 실제로 쓴 값**을 넣는다. 자유 형식이지만 권장:
- 판정에 쓴 파라미터 값(위 `state_params` 키와 같은 이름 사용)
- 판정 순간의 바스켓 구성(`basket`: 업종 → 종목코드) — 명부는 매일 바뀌므로 그 순간을 남긴다
- 재료가 없어 건너뛴 조건(예: `money_ratio: null`, `money_hist_days: 0`)
- 특별한 표지가 있으면 같이(규칙 모델 예: 급락인데 대장주가 **전원** 하락하면 `exogenous_shock: true` + `state_conf` 1.0)
- 깜빡임 방지로 전환을 미루는 중이면 원판정도(규칙 모델 예: `raw_state`, `pending_minutes`)

## 3. 상태 어휘 (state_code)

**실시간 `scope=rt` — 오늘의 단면 8개** (확정)

| 코드 | 뜻 | 한 줄 조건 |
|---|---|---|
| `crash` | 급락(긴급) | 대장주 90% 이상이 각자 −0.5% 이하 (표본 15개 이상) |
| `surge` | 급등 | 대장주 90% 이상이 각자 +0.5% 이상 |
| `theme_up` | 테마주상승 | 하락 대장주 70% 이상인데 +1% 넘게 오른 업종이 있음 → `state_sectors`에 나열 |
| `selloff` | 투매 | 지수 −0.3% 아래 + 대금 폭증 |
| `fire` | 불장 | 지수 +0.3% 위 + 대금 폭증 |
| `up` | 상승 | 지수 +0.3% 위 |
| `down` | 하락 | 지수 −0.3% 아래 |
| `flat` | 횡보 | 지수 ±0.3% 안 |

**주간 `scope=w` — 최근 5거래일 성격 5개** (초안, `rule-temp-w-v0`)

| 코드 | 뜻 |
|---|---|
| `emergency` | 긴급 (오늘 장중 최저가가 전일 종가 −8% 이하) |
| `downtrend` | 하락장 (5거래일 누적 −3% 이하) |
| `uptrend` | 상승장 (5거래일 누적 +3% 이상) |
| `volatile` | 변동장 (5일 평균 진폭이 1년 분포 상위 20%) |
| `box` | 박스권 (위 어디에도 안 걸림) |

우선순위는 위에서부터. 새 어휘를 쓰려면 먼저 합의해야 한다 — 모델을 읽는 쪽이 모르는 코드는 무시된다.

## 4. 지켜야 할 것 (검증 자동 검사 항목과 같다)
1. **미래를 보지 않는다.** 판정 시각(`as_of`) **이전** 데이터만 쓴다. 기준선·분포도 그 시점까지로 자른다.
   (2026-09-14 오딘 자체 시뮬레이션이 2년 전체 분포를 써서 29일 판정이 틀어진 전례가 있다.)
2. **증권 키·주문에 접근하지 않는다.** 외부로 데이터를 보내지 않는다.
3. **append만.** 남의 줄, 원천 표를 고치지 않는다.
4. **한 판정은 1분 안에** 끝낸다(장중 1분 주기).
5. 재료가 없으면 **그 조건을 건너뛰고 `metrics`에 남긴다.** 없는 값을 추정해 채우지 않는다.
6. `model_id`는 `dim_model`에 등록된 값만. 규칙 숫자를 바꾸면 `rule_ver`를 올린다.

## 5. 지금 실제 상태 (2026-09-16 09:47 확인)

| 표 | 줄 수 | 비고 |
|---|---|---|
| `raw_market_snapshot` | 3,662 | 오늘 09:00부터 `kis` 직접 수집 중 — 분당 지수 2줄 + 대장주 42줄 (하루 마감 후 확인: 09:00~15:30 지수 777줄·종목 16,387줄) |
| `state_params` | 100 | 아침 배경 + 장중 매분 |
| `state_market_temp` | 2,184 | 실시간·주간 × (과거 백필 `eod` + 오늘 `live`) |
| `dim_model` | 4 | `rule-temp-rt-v1`, `rule-temp-w-v0`, 기준선 2개 |

- **아직 비는 값**: 장중 `money_ratio` — 과거 같은 시각 대금 이력이 5거래일 쌓여야 나온다(오늘 기준 0일).

- **`old_odin` 복사분**: `acc_amount` 없음. 대금이 필요한 계산은 `source='kis'` 줄만 쓴다.

## 6. 바뀔 때
- 표 칸이 바뀌면 `db/*.sql`과 이 문서를 같이 고치고, 마켓에 올라간 모델에는 **호환 기간**을 준다(방법 미정).
- 파라미터 계산식 변경 → `calc_ver`, 판정 규칙 변경 → `rule_ver`, 모델 자체 변경 → `model_id` 버전.
