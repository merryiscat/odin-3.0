# list_module — 매매 리스트 (그날 볼 종목 뽑기)

> 데이터 흐름: 보다 → **[판단: 시장 온도 → 매매 리스트]** → 매매모델 → 실행 → 보여주다.
> 2,000개 넘는 종목을 다 볼 수 없으니 "오늘 돈이 도는 곳"을 여러 렌즈로 넓게 잡아 태그와 함께 매매모델에 넘긴다.

## 한 줄 방법 (2026-09-17 설계, 사용자 확정)
**렌즈 합집합 + 왜 뽑혔나 태그.** 리스트는 좁히지 않고(시장별 30~50), 최종 선택은 매매모델이 태그로 한다.
기본 모델은 스타일 중립이고, 사용자는 성향에 맞는 리스트 모델을 마트에 추가로 올릴 수 있다.
시장 온도와 대칭인 3단 구조: **종목 파라미터(공용) → 리스트 모델들(마트 단위 `pick`) → 매매모델이 구독.**

## 옛 오딘 교훈 → 여기 규칙
| 교훈(사건) | 규칙 |
|---|---|
| 유니버스가 좁으면 신호가 안 뜬다(코스피200 발동 0회 / 대형주 풀이 연속 상한가를 못 삼) | 유니버스는 **빼기 방식**(보통주 − 거래정지·관리 − 매수 불가). 좁히는 건 렌즈 |
| 감지 → 매매 단선(상한가를 쌓고도 매매 경로 없음) | 감지기는 반드시 `pick_list`에 쓴다. 리스트가 유일한 통로 |
| 국면으로 종목을 고르면 망함(risk_off → 은행만 → 매수 0) | 리스트는 **시장 온도와 독립**. 온도로 거르는 건 매매모델 몫 |
| 계좌가 못 사는 자산이 끝까지 통과(ISA DR·인버스 거부) | `tradable` 표지(DR·외국주권·ELW·신주인수권·펀드·거래정지 제외) |
| 꼭지 추격을 최고 확신으로 오독(한미사이언스 −10.2%) | 배제하지 않고 `blowoff` 경고(당일 +15%↑·이격 +20%↑·거래량 5x↑) |
| 등락률 순위는 전일 종가 대비여야 / 외인기관 일별은 30일 창뿐 / 휴장일 복제 | 순위 파라미터 고정 · 15:35 축적 · 휴장일 저장 금지 |
| 유동성 하한 검증치(20일 평균 50억) | 하한이 아니라 `thin` 경고선 (사용자 결정: 하한 없음) |

## 파일
| 파일 | 하는 일 |
|---|---|
| `stock_params.py` | 종목 파라미터 계산(순수). 일봉 → 등락·대금 배율·거래량 배율·20일/52주 고가 대비·이격·진폭·상한가(값 기준)·연속 상한가·시가 갭·외인/기관 순매수 5일 합·연속일·thin·tradable. 기준일 이후는 안 본다 |
| `run_params.py` | 밤: `raw_stock_ohlc`+`raw_rank_snapshot`+`dim_stock` → `stock_params`(bg_daily, 종목당 1줄, 약 2,760줄). 과거 기록은 저장 안 함(재계산 가능) |
| `pick_rules.py` | 1호 모델 `rule-pick-v1`(규칙 `pick-rules-v1`): 렌즈별 상위 10 합집합, 점수 = 렌즈 수·순위 가중, 상한 40. 기준선 3개(무작위·시총 상위·어제 그대로) |
| `run_pick.py` | 밤: 기준일 파라미터 → 다음 거래일 아침 리스트(`phase=open`) 4모델 기록. `--from/--to`: 과거 재현(메모리 계산, JSON) |
| `measure_pick.py` | 채점: 포착률·알맹이 비율·렌즈별·(기록용) D+1/D+5. 기준선과 나란히 |
| `supa.py` | Supabase REST 도우미(state_module과 같은 내용, import 금지 규칙으로 복사) |
| `tests/` | 파라미터 계산 단위 테스트(창이 기준일 제외·상한가·재료 부족 None·수급 플래그) |

원료는 `data_pipeline`이 채운다: `collect_stock_eod.py`(15:40 전 종목 종가 스냅샷) · `backfill_stock_ohlc_krx.py`(과거) ·
`collect_rank.py`(10분+15:35 순위) · `refresh_dim_stock_master.py`(아침 종목마스터). 표 정의는 `db/`.

## 갱신·최신 줄 규칙 (매매모델과의 계약)
- 밤(15:40 스냅샷 → 파라미터 → 리스트): `phase=open, basis=eod, list_date=다음 거래일, as_of=기준일 15:30`. 시장별 상한 40은 여기만.
- 장중 10분(**아직 미구현** — 순위 축적은 돌지만 리스트 추가 단계는 다음 차례): `phase=intraday, basis=live`, 상한 없음, 삭제 없음, reasons에 `intraday_add`.
- **최신 줄**: 같은 (list_date, market, model_id, stock_code)에서 `as_of`가 가장 늦은 줄. 장중 줄은 아침 사유를 포함해 다시 쓴다.
- `as_of`는 항상 데이터 시각(내일 날짜 금지 — 재현 때 오독 방지).
- 매매모델은 ① 구독한 온도 모델 최신 줄 ② 구독한 리스트 모델의 오늘 줄들 ③ 계좌 상태를 읽는다. 리스트는 온도를 조건으로 뽑히지 않는다.

## 측정 (수익 채점 아님)
포착률(그날 진폭 상위 5%·대금 배율 상위 5%·상한가 종목이 아침 리스트에 몇 % 있었나) · 알맹이 비율(리스트 종목 중 진폭 3%↑ 또는 대금 2배↑) ·
렌즈별 알맹이 비율 · D+1/D+5는 기록만. 기준선: 무작위 40 · 시총 상위 40 · 어제 리스트 그대로.
결과는 아래 "실측"에 적는다.

  (`blowoff` 경고가 그래서 있다). ⑤ 업종 역행 렌즈(59%)는 가장 약함 — 조정 후보.
