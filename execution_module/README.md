# execution_module — 매매(실행) 모듈

> 데이터 흐름: 보다 → 판단 → **[실행]** → 보여주다.
> **⚠️ 비공개 레포(위험·핵심). 절대 공개하지 않는다.**

## 하는 일
주문 의도를 받아서 → **안전장치(가드) 걸고** → 실제 주문을 낸다.

- **읽기**: `model_module`이 쓴 주문 의도 표.
- **쓰기**: 체결/주문 기록 표. 실제 계좌·한투(KIS) 키는 **여기만** 가진다.

## 하드가드는 여기가 소유 (모델이 절대 못 넘김)
- 손절, 비중 상한, 중복 주문 차단 등. "모델은 제안, 실행이 가드."

## 왜 비공개인가
- 공개하면 악성 기여가 사용자의 로컬 키로 나쁜 매매를 시킬 수 있어서.
- 증권 키는 **각 사용자 컴퓨터의 OS 비밀 저장소**(윈도우 자격 증명 관리자)에만. 평문 금지.
