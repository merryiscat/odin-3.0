# 역할 — ohmyPM 1.0.0

모델·effort의 단일 출처는 `docs/workflow.json`. pl에 사용자가 선택한 최고 성능 모델을 배치한다.

| 역할 | 책임 | 변경 경계 |
|---|---|---|
| main | 접수, 단순 작업, pl 연결, 알림, 환경 준비·회수, 로컬 머지 | 등록된 main 체크아웃과 실행 상태 |
| pl | 사용자와 기획·설계·추론, 기준·검증 방법 합의, 최종 품질 판정 | 스펙·설계·검토 기록 작성; 코드 열람과 work 동작 검증 허용 |
| work | 승인된 범위 구현·검증·수정 | 각 작업 manifest의 paths; 다른 work·공용 설정 수정 금지 |

상시 pl2·pl3는 두지 않는다. 기존 터미널과 작업을 자동 종료하지 않는다.
pl은 코드를 대신 수정하지 않는다. main은 품질 판정을 대신하지 않는다.
작고 가역적이며 요청이 완료 기준인 작업은 main 직접 처리, 나머지는 설계 합의 후 진행한다.
pl의 사용자 질문은 main 알림→사용자와 pl 직접 대화로 이어진다. 논의 횟수 제한은 없다.
work는 승인된 버전마다 생성하며 이름은 `T-NNN-r<버전>-<work ID>`다. 자세한 절차는 `protocol.md`.
