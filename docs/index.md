# docs — 오딘 3.0 문서 안내판

> 이 폴더는 "지금 무슨 일이 어디까지 됐는지"를 담는 곳입니다.
> 코드 설명은 각 모듈 폴더의 README에 있고, **일의 진행 상황과 미뤄둔 결정**은 여기에 씁니다.
> 관리 도구(ohmyPM)가 `status.md`와 `pending.md`만 읽어서 할 일 보드와 이슈를 만듭니다.
> 그래서 이 두 파일은 **이름과 위치를 바꾸지 않습니다.**

## 이 폴더의 파일

| 파일 | 무엇 |
|------|------|
| [status.md](status.md) | **작업 보드** — 지금 하는 일 / 다음 할 일 / 끝난 일 |
| [pending.md](pending.md) | **보류 대장** — 지금 정하지 않고 미뤄둔 안건 + 언제 다시 볼지 |
| [log.md](log.md) | **일간보고 로그** — PM과의 대화에서 확정된 것을 한 줄씩 기록 |
| index.md | 이 안내판 |

## 프로젝트 전체 지도

- **한 줄 정체**: 오딘 3.0 = 새로 짓는 자동매매 시스템. 최종 목표는 사람들이 자기 컴퓨터에
  앱을 깔고 **자기 증권계좌·자기 돈**으로 돌리는 제품 + 모델 마트(매매 모델 장터).
- **결정사항 원본(브레인)**: 저장소 루트의 `CLAUDE.md`.
  이 파일은 아직 공개하지 않기로 해서 `.gitignore`로 막혀 있습니다(로컬 컴퓨터에만 있음).
  → 그래서 **깃허브에서 보이는 진행 상황은 이 docs 폴더가 담당**합니다.

## 문서를 쓸 때의 약속

- 사용자는 개발 비전문가입니다. **어려운 말을 쓰면 그 자리에서 한 줄로 뜻을 붙입니다.**
- 날짜는 "지난주" 같은 상대 표현 대신 **2026-09-09처럼 정확히** 적습니다(나중에 읽으면 헷갈립니다).
- 결정이 바뀌면 지우지 말고 **"무엇을 왜 바꿨는지"를 덧붙입니다**(되돌릴 때 근거가 됩니다).
