# T-NNN <제목>

- 상태: 초안 v1 | 검토 반영 v2 | 승인 | 구현 중 | 검증 통과 | 머지
- 등급: S | M | L — 근거 한 줄 (roles.md 등급표 기준)
- 작성: pl, YYYY-MM-DD
- **요청 원문**: "<사용자가 한 말을 그대로. 요약·해석·배경 추가 금지>"

## 목표
요청 원문이 말하는 용도 한 문장. **완료 기준은 여기서만 뽑는다.**
이전 태스크를 예시로 걸 때는 **따를 것과 따르지 말 것을 같이 적는다** — 양식을 가리키면 설계가 따라온다(2026-09-18 T-003).

## 범위
- 안: …
- 밖: … (워커가 손대면 안 되는 것)

## 완료 기준 (관찰 가능한 문장 — 기준 하나에 확인 방법 하나)
기준 하나는 **한 줄**이다. 조항을 여럿 묶지 않는다 — 개수만 세면 문단으로 우회된다.
M은 기준 5개·전체 30줄 이하, L은 8개·한 장 이하.
1. [ ] … — 확인: …
2. [ ] … — 확인: …

## 손대는 파일
- `path/to/file` — 무엇을

## 필요 도구
스킬·MCP·패키지 중 워커가 설치해야 할 것. 없으면 "없음". 여기 없는 도구는 설치 금지.
