# T-NNN 작업 스펙

- 상태: 설계 중 / 사용자 논의 / 구현 승인 / 구현 중 / 검증 중 / 완료
- 버전: 1
- 요청 원문: 사용자 말을 그대로 기록

## 목표와 결정
용도·범위·제외 대상·사용자와 결정한 근거. 논의 횟수 제한 없이 합의한다.

## 완료 기준
관찰 가능한 기준 최대 8개. 기준마다 확인할 입력·동작·통과 조건·검증 방법 하나.
명령으로 검사할 기준과 pl이 실제 동작으로 확인할 기준을 manifest에 대응시킨다.

## 작업과 하네스
work별 소유 경로·의존성·자원·기준·도구·설정. 병렬 가능하면 독립성 근거를 적는다.
기존 도구 우선, 필요한 확장은 사용자와 설계에서 합의한다. manifest와 함께 버전을 고정한다.

## 사용자 결정
질문·답변과 해당 버전의 실제 구현 요청. 스펙 변경은 재합의한다.

## 검증 — pl
기준별 통과/실패와 실제 증거. 결과 커밋·통합 기준·스펙 버전을 함께 기록한다.
